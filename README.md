# お天気お届けします

根据参考截图制作的单页网页。页面还原了浅蓝导航栏、手绘插画、日文商品卡片和祈晴预约表单，并适配窄屏。

公网地址：[Cloudflare Pages](https://weathering-with-you-page-dagdya985.pages.dev/)

直接打开 `index.html` 即可预览；也可以在项目目录启动任意静态文件服务器。

右上角的音符按钮会打开 RADWIMPS《愛にできることはまだあるかい》的官方 YouTube 视频。浏览器可能限制自动播放，此时可在播放器中手动播放，或点击面板中的 YouTube 链接。

表单目前是前端演示：会验证填写内容并显示加入购物车的提示，没有接入支付或订单服务。

Cloudflare Pages 当前采用静态文件直接上传。修改 GitHub 仓库后，需要重新上传站点文件才能更新公网版本。
